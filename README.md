# Fresh Air Cancels Fire

One line of the worst possible advice an AI could give — a make.fun entry for **Worst AI Advice: The 48-Hour Tight Line Open**.

The program composes a single 122-character line in a confident AI-assistant voice and writes it to `/output/entry.txt`.
